# NOTES — журнал изменений

## 2026-09-06
### Исправлено
- Кнопки подсказки: открытые шаги остаются закрашенными с галочкой, следующий шаг подсвечен фоном.
  Раньше зелёной становилась следующая кнопка, и казалось, что нажатие «перепрыгнуло». В подсказке
  про фигуру добавлена фраза, что поле откроет шаг «3. Ход».
- Stockfish не запускался внутри lichess: сайт отдаёт `cross-origin-embedder-policy: require-corp`,
  и Chrome блокировал загрузку скрипта воркера из iframe расширения (`ERR_BLOCKED_BY_RESPONSE`).
  Воркер теперь создаётся из Blob URL, путь к `.wasm` передаётся через hash (`panel/engine.js`).
- Список ходов не читался у залогиненного игрока: lichess использует теги `z7yx` (узкая раскладка)
  и другие вместо `l4x kwdb`. Добавлен селектор для `.col1-moves` и запасной сканер ходов по
  шахматной нотации внутри `.round__app` без привязки к тегам (`content/lichess.js`).
- Кнопка «Открыть разбор партии» показывается и для партий, сыгранных без тренера (`panel/panel.js`).

### Добавлено
- Ручка в правом нижнем углу панели: размер меняется мышью, хранится в `localStorage` (`chess-coach-size`)
  в единицах масштаба 1, кнопки A−/A+ масштабируют и его. На время перетаскивания iframe не ловит мышь.
- Проверка расширения через Playwright (Python): `launch_persistent_context` с
  `--load-extension`, открыть партию, прочитать текст `#view` во фрейме `chrome-extension://`.
  Аноним в узком окне попадает на страницу анализа, а не round — раскладку игрока так не воспроизвести.
