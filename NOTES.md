# NOTES — журнал изменений

## 2026-09-08
### Исправлено (по итогам ревью кода)
- История: кнопка «Удалить» открывала разбор — клик перехватывала карточка с `data-open-game`.
- Перемотка в начало партии анализировала финальную позицию: `activeIdx === -1` означало
  и «стартовая позиция», и «активный ход не найден».
- Переворот доски менял «мой цвет»: теперь цвет берётся из позиции своего ника, а не из ориентации.
- Ник игрока и «рейтинговость» сравнивались подстрокой: `bobby` совпадал с `bob`,
  «Нерейтинговая» содержит «рейтинг».
- Takeback оставлял в сохранённой партии несуществующие ходы.
- Взятие на проходе описывалось полем хода вместо поля снятой пешки.
- Пешка не могла считаться связанной; ранний размен ферзей выключал дебютную фазу.
- Вердикт по ходу выносился на глубине 10 и не пересчитывался на полной глубине.
- «Наказание» объяснялось в позиции до хода — неверный SAN и потерянные объяснения.
- Гонки: параллельные копии `onGame`, устаревшие запросы к движку после ожидания воркера,
  чтение-изменение-запись индекса в `store.js`.
- Прокрутка списка ходов утаскивала всю панель; ссылка на урок перестала прокручивать после
  перевода `render()` на `requestAnimationFrame`.
- `MutationObserver` слушал весь документ; запасной сканер ходов обходил всё поддерево на каждом тике.

### Добавлено
- `npm test` — 29 юнит-тестов, `npm run lint`, `npm run e2e`, `npm run zip`.
- `AGENTS.md`, `CLAUDE.md`, `docs/INSTALL.md`, `docs/ARCHITECTURE.md`.

## 2026-09-07
### Изменено
- Разбор партии: список ходов перенесён под доску и навигацию, ограничен по высоте с прокруткой,
  текущий ход автоматически прокручивается в видимую область.
- Масштаб A−/A+ и размер окна панели (ручка в углу) — независимые настройки: zoom меняет только
  содержимое iframe, размер хранится в пикселях.

## 2026-09-06
### Исправлено
- Кнопки подсказки: открытые шаги остаются закрашенными с галочкой, следующий шаг подсвечен фоном.
  Раньше зелёной становилась следующая кнопка, и казалось, что нажатие «перепрыгнуло». В подсказке
  про фигуру добавлена фраза, что поле откроет шаг «3. Ход».
- Stockfish не запускался внутри lichess: сайт отдаёт `cross-origin-embedder-policy: require-corp`,
  и Chrome блокировал загрузку скрипта воркера из iframe расширения (`ERR_BLOCKED_BY_RESPONSE`).
  Воркер теперь создаётся из Blob URL, путь к `.wasm` передаётся через hash (`panel/engine.js`).
- Список ходов не читался у залогиненного игрока: lichess использует теги `z7yx` (узкая раскладка)
  и другие вместо `l4x kwdb`. Добавлен селектор для `.col1-moves` и запасной сканер ходов по
  шахматной нотации внутри `.round__app` без привязки к тегам (`content/lichess.js`).
- Кнопка «Открыть разбор партии» показывается и для партий, сыгранных без тренера (`panel/panel.js`).

### Добавлено
- Ручка в правом нижнем углу панели: размер меняется мышью, хранится в `localStorage` (`chess-coach-size`)
  в единицах масштаба 1, кнопки A−/A+ масштабируют и его. На время перетаскивания iframe не ловит мышь.
- Проверка расширения через Playwright (Python): `launch_persistent_context` с
  `--load-extension`, открыть партию, прочитать текст `#view` во фрейме `chrome-extension://`.
  Аноним в узком окне попадает на страницу анализа, а не round — раскладку игрока так не воспроизвести.
