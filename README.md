# ♞ Шахматный тренер для lichess

Расширение для Chrome, которое превращает игру на [lichess.org](https://lichess.org) в занятие с тренером.
Оно не просто показывает лучший ход — оно учит **думать**: задаёт правильные вопросы перед ходом,
объясняет *почему* ход хорош, разбирает каждый ваш ход после партии и ведёт курс уроков.

Всё работает локально в браузере: движок Stockfish 18 запускается внутри расширения,
партии и настройки хранятся только в вашем Chrome. Никаких серверов, аккаунтов и ключей.

## Установка

Подробная инструкция со скриншотами шагов: **[docs/INSTALL.md](docs/INSTALL.md)**. Коротко:

1. Скачайте репозиторий: кнопка **Code**, затем **Download ZIP**, и распакуйте архив.
2. Откройте `chrome://extensions` и включите **Режим разработчика** справа вверху.
3. Нажмите **Загрузить распакованное расширение** и выберите папку с файлом `manifest.json`.
4. Откройте партию на lichess — справа появится панель «♞ Тренер».

Работает в Chrome, Edge, Brave, Arc и других браузерах на Chromium.

> Если вы пользуетесь Claude Code или другим ИИ-агентом, просто откройте папку проекта и попросите:
> «установи это расширение». Агент прочитает [AGENTS.md](AGENTS.md) и проведёт вас по шагам.

## Возможности

- **Невидимый режим (по умолчанию).** Вы играете сами, без подсказок. Расширение молча анализирует
  каждую позицию и сохраняет партию. В любой момент можно нажать «Включить подсказки с этого хода».
- **Режим учителя.** Перед ходом — «модель мышления» под конкретную позицию (вы под шахом? соперник побил?
  что-то висит? какая фаза партии?). Подсказка открывается постепенно: *идея → какой фигурой → ход*.
- **Объяснения по-человечески.** Для каждого хода-кандидата: выигрыш материала, вилка, связка, шах, защита от
  угрозы, развитие, центр, открытая линия, проходная пешка, активность короля и так далее. Плюс линия-план движка.
- **Что задумал соперник.** Отдельный поиск угроз: что сыграл бы соперник, если бы ход был его.
- **Разбор каждого хода.** Лучший, отличный, хороший, неточность, ошибка, грубая ошибка; что было лучше
  и почему; чем соперник теперь может наказать; ссылка на урок по теме ошибки.
- **Итоги партии.** Точность, статистика, ключевые моменты, «что изучить».
- **Разбор с перемоткой.** Встроенная мини-доска, кнопки ⏮ ◀ ▶ ⏭ и клавиши ←/→, график оценки, список ходов
  с цветовой разметкой, анализ любой позиции движком.
- **История партий.** Все партии сохраняются в браузере; любую можно открыть и разобрать позже.
- **Курс из 13 уроков.** Ценность фигур, «шахи-взятия-угрозы», профилактика, дебют, безопасность короля,
  вилка, связка, активность, пешки, план, расчёт, эндшпиль, блиц. Каждый урок — модель мышления и чек-лист.
- **Стрелки на доске lichess** для лучшего хода и угрозы (в видимом режиме).
- **Масштаб панели** кнопками A− и A+, перетаскивание за заголовок, сворачивание.

## Как этим учиться

1. Играйте в невидимом режиме. После партии откройте вкладку **Разбор**: пройдите по ключевым моментам,
   прочитайте, что было лучше и почему.
2. Во вкладке **Уроки** прочитайте урок, который рекомендован по вашим ошибкам. Один урок в день.
3. Играя нерейтинговую партию, включите подсказки в режиме учителя: сначала отвечайте на вопросы
   «модели мышления», затем сверяйтесь с идеей, и только потом смотрите ход.
4. Раз в неделю просматривайте вкладку **История**: какие ошибки повторяются?

## Важно про правила lichess

Использование движка **во время рейтинговой партии** — это читерство по правилам lichess и ведёт к бану.
Панель предупредит, если партия рейтинговая. Для обучения с подсказками играйте **нерейтинговые** партии
(или партии с компьютером), а рейтинговые разбирайте после окончания — невидимый режим для этого и нужен.

## Приватность

Расширение не делает ни одного сетевого запроса. Движок Stockfish собран в WebAssembly и работает
внутри браузера. Партии, настройки и прогресс по урокам лежат в `chrome.storage.local`, то есть
только на вашем компьютере, и удаляются вместе с расширением. Разрешения в манифесте — только
`storage` и доступ к страницам lichess.org.

## Для разработчиков

```bash
npm test          # юнит-тесты (Node, без зависимостей)
npm install       # только если нужен линтер
npm run lint      # ESLint
npm run e2e       # сквозной тест в Chromium (нужен Playwright)
```

Сборки нет: браузер грузит ES-модули напрямую, поэтому после правки достаточно нажать значок
обновления на `chrome://extensions`.

- Устройство проекта и потоки данных: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Правила для ИИ-агентов и диагностика: [AGENTS.md](AGENTS.md)

```
manifest.json           манифест расширения (Manifest V3)
content/lichess.js      чтение ходов со страницы lichess, панель, стрелки
panel/panel.{html,css,js}  панель тренера (iframe расширения)
panel/engine.js         обёртка над Stockfish (UCI) в Web Worker
panel/explain.js        объяснение ходов «человеческим языком»
panel/coach.js          оценка ходов, модели мышления, итоги партии
panel/lessons.js        курс уроков
panel/board.js          мини-доска для разбора
panel/store.js          хранилище партий (chrome.storage.local)
engine/                 Stockfish 18 lite (WASM, GPLv3)
lib/chess.js            chess.js (BSD-2-Clause)
test/                   юнит-тесты и сквозной тест
```
