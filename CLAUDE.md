# Инструкции для Claude Code

Смотрите [AGENTS.md](AGENTS.md) — там всё: как установить расширение пользователю,
как дорабатывать код и как диагностировать проблемы.

Кратко:

- Проект — Chrome-расширение (Manifest V3) без сборки, ES-модули грузятся браузером напрямую.
- Тесты: `npm test` (Node, без зависимостей). Линтер: `npm run lint` (нужен `npm install`).
- Архитектура и потоки данных: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
- Не редактируйте `lib/chess.js` и `engine/` — это сторонние библиотеки.
- Весь текст из DOM lichess экранируйте через `esc()` перед вставкой в HTML.
- Никаких сетевых запросов: расширение работает полностью локально.
