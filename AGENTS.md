# Инструкции для ИИ-агента

Этот файл читают Claude Code и другие агенты, которым передали этот репозиторий.
Он описывает два сценария: **установить расширение пользователю** и **дорабатывать код**.
Отвечайте пользователю на его языке; по умолчанию русский.

## Что это за проект

Chrome-расширение (Manifest V3) для lichess.org. Оно работает как шахматный тренер:
подсказывает ходы с объяснениями, разбирает сыгранные партии, ведёт историю и курс уроков.
Движок Stockfish и вся логика работают локально в браузере, сеть не используется.

Ключевое требование безопасности: расширение не отправляет данные никуда наружу.
Не добавляйте сетевые запросы, аналитику, телеметрию и внешние CDN.

## Сценарий 1. Установить расширение пользователю

Проведите человека по шагам, выполняя за него всё, что можно выполнить командой.
Установку расширения Chrome нельзя автоматизировать: последние три клика делает человек.

1. Убедитесь, что файлы на месте: в корне лежит `manifest.json`, папки `panel/`, `content/`,
   `engine/`, `lib/`, `icons/`. Файл `engine/stockfish-18-lite-single.wasm` должен весить около 7 МБ.
   Если он весит несколько килобайт, значит репозиторий скачан без Git LFS или архив распакован
   не полностью: попросите скачать заново.
2. Покажите пользователю абсолютный путь к папке и скопируйте его в буфер обмена:
   - macOS: `pwd | pbcopy`
   - Linux: `pwd | xclip -selection clipboard`
   - Windows (PowerShell): `(Get-Location).Path | Set-Clipboard`
3. Откройте страницу расширений:
   - macOS: `open -a "Google Chrome" "chrome://extensions"`
   - Linux: `google-chrome "chrome://extensions"`
   - Windows: `start chrome chrome://extensions`
   Если Chrome нет, подойдут Edge, Brave, Arc, Vivaldi и другие браузеры на Chromium.
4. Попросите пользователя сделать три действия и дождитесь подтверждения:
   1) включить «Режим разработчика» (переключатель справа вверху);
   2) нажать «Загрузить распакованное расширение»;
   3) в диалоге выбора папки вставить путь (macOS: Cmd+Shift+G, затем Cmd+V) и подтвердить.
5. Проверка: откройте любую партию на lichess, например `https://lichess.org/`, и попросите
   подтвердить, что справа появилась зелёная панель «♞ Тренер». На завершённой партии
   она сразу показывает итоги, в живой партии — «Невидимый режим».
6. Если панель не появилась, действуйте по разделу «Диагностика» ниже.

## Сценарий 2. Доработка кода

Перед изменениями прочитайте `docs/ARCHITECTURE.md` — там разбор модулей и потоков данных.
Правила работы:

- Сборки нет. Это ES-модули, которые Chrome грузит напрямую. Не добавляйте бандлер и зависимости
  времени выполнения без явной просьбы.
- После изменений запускайте `npm test` (юнит-тесты на Node, зависимостей не требуют).
- `npm run lint` требует установленного ESLint (`npm install`), это необязательный шаг.
- Не редактируйте `lib/chess.js` и содержимое `engine/` — это сторонние библиотеки.
- Любой текст, попадающий в HTML панели, экранируйте функцией `esc()` из `panel/panel.js`.
  Данные из DOM lichess считаются недоверенными.
- Тексты интерфейса и объяснений — на русском.

## Диагностика

**Панель не появилась.** Обновите страницу lichess. Если не помогло, откройте `chrome://extensions`,
нажмите значок обновления у расширения, снова обновите страницу. Проверьте, что в карточке
расширения нет красной надписи «Ошибки».

**Панель пишет «Жду партию» или «Не удалось разобрать ходы».** lichess изменил разметку.
Селекторы собраны в `content/lichess.js`, функция `readGame`: `l4x kwdb` — список ходов в партии,
`.tview2 move` — ходы на странице анализа, `.cg-wrap` — доска, `.ruser-top` и `.ruser-bottom` —
игроки, `.game__meta` — тип партии. Найдите актуальные селекторы в DOM страницы и обновите их.

**Панель пишет «Не удалось запустить Stockfish».** В карточке ошибки есть диагностика: размеры
файлов движка, поддержка WebAssembly и SIMD, версия браузера. Частые причины: файл `.wasm`
скачан не полностью, старая версия браузера без поддержки WebAssembly SIMD.

**Ошибки в консоли.** Логи панели видны в консоли страницы lichess (она работает в iframe).
Откройте инструменты разработчика на странице lichess и выберите контекст `panel.html`.

## Чего делать не нужно

- Не советуйте включать подсказки в рейтинговых партиях: это нарушает правила lichess и ведёт к бану.
  Расширение само предупреждает об этом, предупреждение убирать нельзя.
- Не добавляйте автоматические ходы за пользователя. Расширение только объясняет и учит.
- Не собирайте статистику пользователя за пределами его браузера.
