# Установка за 5 минут

Расширение ставится «распакованной папкой»: это обычный способ установки для расширений,
которых нет в магазине Chrome. Ничего собирать и компилировать не нужно.

Подойдёт любой браузер на Chromium: Chrome, Edge, Brave, Arc, Vivaldi, Opera.

## Шаг 1. Скачать файлы

Вариант А, архивом (проще):

1. Откройте страницу репозитория, нажмите зелёную кнопку **Code**, затем **Download ZIP**.
2. Распакуйте архив. Запомните папку, в которой лежит файл `manifest.json`.

Вариант Б, через git:

```bash
git clone https://github.com/pdoronin/chess.git chess-coach
cd chess-coach
```

Проверьте, что файл `engine/stockfish-18-lite-single.wasm` весит около 7 МБ.
Если он весит несколько килобайт, архив скачался не полностью, повторите загрузку.

## Шаг 2. Установить в браузер

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`, в Brave — `brave://extensions`).
2. Включите **Режим разработчика** — переключатель справа вверху.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку из шага 1 (ту, где лежит `manifest.json`).

На macOS в диалоге выбора папки удобно нажать Cmd+Shift+G и вставить путь.

В списке появится «Шахматный тренер для lichess». Если в карточке горит красная надпись
«Ошибки», откройте её и посмотрите текст: обычно это означает, что выбрана не та папка.

## Шаг 3. Проверить

Откройте lichess.org и любую свою партию. Справа появится зелёная панель **♞ Тренер**.

- Панель перетаскивается за заголовок.
- Кнопки **A−** и **A+** меняют размер панели, **–** сворачивает её.
- На завершённой партии сразу видны итоги и кнопка «Открыть разбор партии».

## Обновление

Скачайте новую версию поверх старой (или `git pull`), затем на `chrome://extensions`
нажмите значок обновления в карточке расширения и перезагрузите страницу lichess.

## Удаление

На `chrome://extensions` нажмите «Удалить» в карточке расширения. Сохранённые партии
удалятся вместе с ним: они хранятся только в браузере.

## Частые вопросы

**Панель не появилась.** Обновите страницу lichess. Если не помогло — на `chrome://extensions`
нажмите значок обновления у расширения и снова обновите страницу.

**Chrome предупреждает о расширениях в режиме разработчика при каждом запуске.** Это нормально
для расширений не из магазина. Предупреждение можно закрыть, расширение продолжит работать.

**Пишет «Не удалось запустить Stockfish».** В карточке ошибки есть диагностика. Чаще всего
помогает обновление браузера до последней версии или повторное скачивание архива.

**Данные куда-то отправляются?** Нет. Движок работает внутри браузера, партии хранятся
в локальном хранилище расширения. Сетевых запросов расширение не делает.

**Можно ли пользоваться в рейтинговых партиях?** Подсказками — нельзя, это нарушает правила
lichess и ведёт к блокировке аккаунта. Для рейтинговых партий оставляйте невидимый режим:
он молча анализирует партию и покажет разбор после её окончания.
